# POUL — Phoenix Card Deck v1.0
### 40 Cards · 6 Categories · 3 Rarity Tiers

---

## Card Schema Reference

Each card contains:
- **ID** — unique identifier
- **Title** — the activity name (specific, not generic)
- **Description** — one sentence that sells the experience
- **Category** — Adventure / Foodie / Chill / Social / Active / 8-Ball
- **Rarity** — Common / Rare / Legendary
- **Cost** — $ (free–$15) / $$ ($15–$50) / $$$ ($50+)
- **Duration** — estimated time commitment
- **Time of Day** — Morning / Afternoon / Evening / Any
- **Season** — Year Round / Oct–Apr (cool season) / May–Sep (heat season)
- **Bonus Challenge** — optional micro-dare for extra Spark
- **Spark Reward** — base points for completion (before bonus)

## Draw Weighting (for game logic)

Commons draw at 3x frequency of Rares. Legendaries draw at 0.5x frequency of Rares.

Normalized weights:
- Common: 60%
- Rare: 30%
- Legendary: 10%

8-Ball category draws from its own pool only (no cross-category draws).
